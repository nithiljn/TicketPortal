# TicketPortal 🎫

A modern, full stack personal Ticket and Daily Work Tracking Portal.

## 🚀 Tech Stack
- **Frontend & Backend:** Next.js (React)
- **API:** GraphQL (Queries & Mutations)
- **Database:** Supabase (PostgreSQL)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## 📌 Features
- Personal Ticket Management (Todo, In Progress, Done, Blocked)
- Daily Work Logs & Standup Notes
- Priority & Tagging system
- Real-time search & filters
